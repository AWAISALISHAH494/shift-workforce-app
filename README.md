## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Expo Go app (for testing)

### Installation

```bash
# Install dependencies
npm install

# Start development server
npx expo start
```

### Running the App

```bash
# Start Expo
npx expo start

# Scan QR code with Expo Go app
```
